## Italiano

- Corretta la tabella che poteva restare tagliata dopo una scansione. Il riepilogo ora occupa una sola riga.
- Le nuove versioni dell’app compaiono nella Home. **Vedi novità** mostra le note nella lingua dell’interfaccia.
- Ripristinata la selezione degli aggiornamenti compatibili con WinGet 1.30.310. Le rimozioni preventive richiedono una conferma separata.
- Setup e Portable sono distribuiti senza firma Authenticode. Dalla 2.0.0, usa il Setup interattivo o sostituisci il Portable a programma chiuso. Verifica il file con il relativo `.sha256`. Impostazioni e cronologia restano nello stesso profilo Windows.

## English

- Fixed a table that could get cut off after a scan. The results now have a single summary line.
- New app versions appear on Home. **See what’s new** shows the release notes in your app language.
- Restored selection for compatible updates with WinGet 1.30.310. Removing the previous version first requires separate approval.
- Setup and Portable are distributed without an Authenticode signature. From 2.0.0, run Setup interactively or close the app and replace the Portable executable. Verify the file against its `.sha256` checksum. Settings and history stay in the same Windows profile.
